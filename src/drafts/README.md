# src/drafts — תוכן שמור שאינו מסלול ציבורי

קבצים כאן **אינם** מסלולי אתר: הם יושבים מחוץ ל-`src/pages/`, ולכן אינם
נבנים, אינם מקושרים ואינם מופיעים ב-sitemap. הם נשמרים בריפו במלואם.

## `chativa-elyona/`

עמודי החטיבה העליונה (3/4/5 יח״ל, בחינות ומידע מנהלי, חומרי הוראה ומאגרים).

הכניסה הציבורית לחטיבה העליונה מתכנסת בשלב זה לעמוד אחד —
`/chativa-elyona/` ("העמוד יתעדכן בהמשך"). חמש הכתובות הישנות ממשיכות לחיות
כ**הפניית HTTP אמיתית** אליו, דרך מקור התאימות היחיד
[`src/lib/legacyRedirects.mjs`](../lib/legacyRedirects.mjs) — בלי manifest מקביל,
ובלי עמוד 200 עם meta-refresh.

**התוכן לא נמחק.** מקורות הנתונים שהעמודים צורכים חיים כרגיל:
`src/data/mafmar.ts` (טווחי MAF) ו-`src/data/units.ts` (`hsUnit`).
כדי להחזיר עמוד לאוויר — מעבירים את הקובץ חזרה ל-`src/pages/chativa-elyona/`
ומוציאים את הכתובת מ-`LEGACY_REDIRECTS`. הייבואים היחסיים (`../../layouts`,
`../../components`, `../../data`) תקפים בשתי התיקיות כאחת, ולכן ההעברה
לשני הכיוונים היא הזזת קובץ בלבד.
