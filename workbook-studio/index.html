סטודיו החוברת עבר לריפו פרטי

קוד הסטודיו הועבר מהריפו הציבורי של האתר אל ריפו פרטי, כדי שכלי הניהול האישי לא יהיה גלוי לציבור. הכלי עצמו לא בוטל — הוא ממשיך לעבוד ולפרסם לאתר בדיוק כמו קודם.

אם הגעת לעמוד הזה, פרויקט ה-Vercel של הסטודיו עדיין מצביע לריפו הישן. שני שינויים ותחזור לעבוד:

  1. ב-Vercel, בפרויקט הסטודיו: Settings → Git → החלף את הריפו ל-jerusalem-booklet-studio.
  2. באותו מסך: Root Directory → שנה מ-workbook-studio ל-/.

משתני הסביבה, ה-OAuth App וכתובת הפרויקט נשארים כפי שהם — אין צורך לשנות אותם.

לאחר ההחלפה אפשר למחוק את התיקייה workbook-studio מהריפו הציבורי; היא נשארה כאן רק כדי שההעברה לא תיפול בשקט.
